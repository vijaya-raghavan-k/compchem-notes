Moving on the potential energy surface · 2.4

Finding transition states

Goal: understand how eigenvector-following (P-RFO) optimizers climb along one mode while descending along the others, how the nudged elastic band finds a whole reaction path, and how to turn both into a reliable transition-state workflow.

Step 1 · See it

Climbing to a saddle on a real test surface

The Müller–Brown surface is the standard two-dimensional test for reaction-path methods: three minima (A, B, C) and two saddle points (TS1, TS2). Choose a starting point and compare two optimizers: one that minimizes, and one that searches for a first-order saddle by following the lowest Hessian eigenvector uphill.

P-RFO transition-state searchminimizershaded: one negative Hessian eigenvalue

Starting anywhere in the shaded regions, where the Hessian already has one negative eigenvalue, the transition-state search lands quickly on the nearest saddle. Starting deep inside a well is harder: the method must climb out along the softest direction, and which saddle it finds depends on where it starts. This is why a good initial guess and an initial Hessian with the right negative eigenvalue matter so much in practice.

Step 2 · Calculate it

Up along one mode, down along the rest

  1. Write the gradient in the Hessian's eigenvectors (lesson 1.9): \(g_i = \mathbf v_i\cdot\mathbf g\). In those coordinates the quadratic model separates, and the Newton step is simply \(\Delta q_i = -g_i/\lambda_i\) for each mode.
  2. Take the saddle \(E = -x^2 + y^2\) (eigenvalues \(-2\) and \(2\) along \(x\) and \(y\)) at the point \((0.3,\ 0.2)\). The gradient is \((-0.6,\ 0.4)\), so \[ \Delta x = -\frac{-0.6}{-2} = -0.3, \qquad \Delta y = -\frac{0.4}{2} = -0.2 \] One step lands exactly on the saddle at the origin. Along \(x\) the energy rises from \(-0.09\) to 0 (uphill); along \(y\) it falls from 0.04 to 0 (downhill).
  3. A minimizer would refuse the uphill part: it flips any step that raises the energy, so it slides away along \(x\). A transition-state optimizer deliberately keeps that one mode uphill.
  4. P-RFO (partitioned rational function optimization) makes this robust far from the saddle, where the model is not exact. It shifts each denominator: maximize along the chosen mode, minimize along all others, \[ \Delta q_1 = -\frac{g_1}{\lambda_1 - \mu_p}, \quad \mu_p = \tfrac12\lambda_1 + \tfrac12\sqrt{\lambda_1^2 + 4g_1^2}; \qquad \Delta q_i = -\frac{g_i}{\lambda_i - \mu_n}\ \ (i \ge 2) \] The shifts \(\mu_p > \lambda_1\) and \(\mu_n < \lambda_i\) guarantee the right direction along every mode, even when the curvature signs are wrong.

The nudged elastic band

NEB does not need a guess of the saddle, only the two minima. It places a chain of "images" between them and moves each image with a modified force: the true force with its component along the path removed, plus a spring force along the path that keeps the images evenly spaced. With \(\hat{\boldsymbol\tau}_i\) the local path direction,

\[ \mathbf F_i = -\nabla E(\mathbf R_i) + \left(\nabla E(\mathbf R_i)\cdot\hat{\boldsymbol\tau}_i\right)\hat{\boldsymbol\tau}_i + k\left(|\mathbf R_{i+1} - \mathbf R_i| - |\mathbf R_i - \mathbf R_{i-1}|\right)\hat{\boldsymbol\tau}_i \]

The images relax sideways into the valley until the chain lies on the minimum-energy path. In the climbing-image variant the highest image feels no springs and has its force along the path inverted, so it climbs to the saddle exactly.

Step 3 · Apply it to chemistry

A practical transition-state workflow

  1. Build a guess. From chemical intuition (stretch the breaking bond, shorten the forming one), a relaxed scan along the key coordinate (lesson 1.3), or an NEB between optimized reactant and product.
  2. Compute the Hessian at the guess. A model Hessian has no negative eigenvalue; the optimizer would have nothing to climb along. Check that the lowest computed mode looks like the reaction.
  3. Run the TS optimization (P-RFO or eigenvector following), telling it which mode to follow if the lowest is not the reaction.
  4. Verify: one imaginary frequency with the right motion (lesson 1.11), then an IRC (lesson 2.5).

In AMS these steps map onto the transition-state search task, the NEB task and the PES scan task; Gaussian offers Opt=(TS,CalcFC) and the synchronous-transit QST2/QST3 methods. Climbing-image NEB is particularly useful when the reaction is not well described by one coordinate, for example concerted multi-bond rearrangements.

Going deeper: mode tracking, NEB details and Hessian-free methods

Mode tracking. The lowest eigenvector can change character during the search, for instance when a methyl rotation becomes softer than the reaction mode. Robust implementations follow the mode with the largest overlap \(|\mathbf v_\text{new}\cdot\mathbf v_\text{old}|\) with the previous step's mode (lesson 1.2), not simply the lowest one.

Tangents and kinks. The simple tangent \(\mathbf R_{i+1} - \mathbf R_{i-1}\) produces kinks in curved regions. The improved tangent of Henkelman and Jónsson uses the neighbour higher in energy, with a weighted average at extrema; that is what the figure uses. Too few images can cut corners and miss intermediates; too many waste gradients. Each image costs one gradient per iteration.

String methods. Instead of springs, the string method reparametrizes images to equal spacing after each step. The growing string method adds images from both ends inward, which avoids wasting effort on high-energy regions of the initial interpolation.

Dimer method. Without any Hessian, two closely spaced images (a "dimer") are rotated to minimize their energy; the rotated orientation is the lowest-curvature direction, found by minimizing the Rayleigh quotient of lesson 1.9 using only gradients. The dimer then translates uphill along it. This scales to very large systems where Hessians are unaffordable.
